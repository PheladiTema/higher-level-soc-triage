# Higher Level SOC Triage

## Overview

This project was completed as part of my Zaio Cybersecurity Bootcamp and focused on Security Operations Centre (SOC) alert triage and investigation.

The project provided practical exposure to analysing security alerts, investigating suspicious activity, identifying relevant evidence and determining appropriate responses to potential security incidents.

## Objectives

- Understand the SOC alert triage process
- Analyse security alerts and investigate suspicious activity
- Identify indicators of compromise (IOCs)
- Review event information and supporting evidence
- Distinguish between legitimate activity and potential security incidents
- Develop structured incident investigation and reporting skills
- Understand appropriate containment and response actions

## Key Skills

- SOC alert triage
- Security event analysis
- Incident investigation
- Indicator of Compromise (IOC) identification
- Log analysis
- Threat detection
- Incident response fundamentals
- Security documentation and reporting
- Analytical problem-solving

## Investigation Process

The exercises followed a structured approach to security investigation:

1. Review the initial security alert
2. Identify the affected user, host or system
3. Examine available logs and security events
4. Identify suspicious indicators and activity
5. Establish a timeline of relevant events
6. Determine whether the activity appeared legitimate or suspicious
7. Document findings
8. Recommend appropriate containment or response actions
